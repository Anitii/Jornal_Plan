三本計畫本

MONTHLY + Y：365 Timeline、Yearly、月曆、Monthly Navigation。月曆裡用螢光筆標記的文字，會自動寫一行到當月的 Yearly（之後可自由修改）。

WEEKLY + N：每天最上面一格「FROM MONTHLY」和月曆同一格連動；N 是 Free note。

DAILY LOG：右邊時間表每格 10 分鐘。在空格上拖曳＝新增任務；拖曳任務＝移動；拖右邊邊緣＝調整長度；點任務＝改名／顏色／完成／刪除。左邊 check list 滑過會出現 ⠿，拖到時間表就排進去。

MARKDOWN 快捷語法

**文字**粗體
*文字*斜體
~~文字~~刪除線
`文字`程式碼標籤
==文字==螢光筆
# ＋空白標題（行首）
- ＋空白• 項目符號（行首）
[] ＋空白☐ 可勾選方框（行首）
> ＋空白引言（行首）

選取文字會跳出工具列（馬卡龍螢光筆、字色）。單行格子 Enter 跳下一格；內容超出時旁邊會出現可拖曳的捲動條。

☁ 跨裝置同步（GitHub）

你的內容會存成 GitHub repo 裡的一個 JSON 檔，每台裝置都連到同一個檔案就能同步。請用 Private repo 放資料（不要用放網頁的公開 repo）。

Token 只存在這台裝置的瀏覽器裡，只用來呼叫 GitHub API。建議用 Fine-grained token，只授權資料 repo 的「Contents：Read and write」。
