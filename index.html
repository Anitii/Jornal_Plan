☁ 跨裝置同步（GitHub）

你的內容會存成 GitHub repo 裡的一個 JSON 檔，每台裝置都連到同一個檔案就能同步。請用 Private repo 放資料（不要用放網頁的公開 repo），只有你看得到。

Token 只存在這台裝置的瀏覽器裡，不會上傳到任何地方（只用來呼叫 GitHub API）。建議用 Fine-grained token，只授權資料 repo 的「Contents：Read and write」。

MARKDOWN 快捷語法

**文字**粗體
*文字*斜體
~~文字~~刪除線
`文字`程式碼標籤
==文字==螢光筆
# ＋空白標題（行首）
- ＋空白• 項目符號（行首）
[] ＋空白☐ 可勾選方框（行首）
> ＋空白引言（行首）
Ctrl+B / I / U粗體 / 斜體 / 底線

選取文字後會跳出工具列，可套用馬卡龍色的螢光筆底色與字體顏色。單行格子按 Enter 會跳到下一格，Shift+Enter 換行；內容超出時，滑鼠移到格子上就會出現捲動條。
